## Findings and limitations

- **Field names differ from the README for discharge:** the files contain `Current_load` / `Voltage_load`, not `Current_charge` / `Voltage_charge`.
- **Current sign:** `Current_measured` is ≈ +1.5 A during CC charge and ≈ −2 A during discharge (median discharge current per battery: B0005 -2.01 A, B0006 -2.01 A, B0007 -1.99 A, B0018 -2.01 A).
- **`Current_load` sign is inconsistent between discharge records** (B0005: {'negative': 31, 'positive': 137}; B0006: {'negative': 31, 'positive': 137}; B0007: {'negative': 31, 'positive': 137}; B0018: {'positive': 132}). It is not used for integration or as a model input.
- **Ambient temperature** is 24 °C in every record, so it carries no information for modelling.
- **Truncated charge records:** some charge records contain only a handful of samples; their charge features are left missing (not zero).
- **Discharge cutoffs differ** (README: 2.7, 2.5, 2.2, 2.5 V for B0005/6/7/18), but `Capacity` is documented as capacity to 2.7 V. Integrating current to the 2.7 V crossing agrees with `Capacity` to within about 0.6 % (details in `results/soc_assessment.md`).
- **Rated capacity:** the README gives 2 Ah (EOL = 30 % fade, 2 → 1.4 Ah). B0006's first measured capacities exceed 2 Ah, so its early SOH values are above 100 %. These are kept unclipped.
- **Suspect charge records:** the charge immediately before discharge #31 in B0005/B0006/B0007 (record 84) reads a terminal voltage above 8 V, which is impossible for a cell charged at 4.2 V. The raw data are kept, but features from any charge record above 4.5 V are set to missing and flagged in `charge_feature_flag`. One B0018 charge record (114) contains non-finite samples.
- **Impedance:** `Re` and `Rct` are real scalars per test, all positive and finite. Not every discharge is preceded by an impedance test (B0005–B0007: none before discharges 1–19 and a few later ones; B0018: 53 tests in total). Per-battery match coverage is in `results/tables/soh_match_coverage.csv`. Unmatched cycles keep missing impedance values; nothing is forward-filled.
- The impedance spectra (`Battery_impedance`, `Rectified_Impedance`, complex) are not used beyond `Re`/`Rct`.
- **No measured SOC exists** in the files; any SOC target must be a derived reference.
