# SOC reference assessment

Generated by `python scripts/train_soc.py`. All numbers below are computed from the supplied files.

## Evidence inspected

- Discharge records: 636; accepted as SOC segments: 636; rejected: 0 
- Current sign: `Current_measured` is negative during discharge in every record; discharge current is taken as `-Current_measured`. Mean load current over accepted segments: 1.989–2.013 A (README: 2 A CC).
- `Current_load` changes sign between records (positive in some, negative in others), so it is not used for integration.
- Time: strictly increasing within every record; largest step 20.5 s (gap limit 60 s). No resets inside a record, so each discharge record is one segment.
- Initial condition: lowest discharge start voltage 4.158 V. Each discharge follows a CC-CV charge to 4.2 V/20 mA (README), so SOC0 = 100 % is used.
- Integration vs measured capacity: integrating to the first sample below 2.7 V under load gives 0.9938 / 0.9963 / 0.9972 (min / median / max) times the `Capacity` field. Tolerance used: ±2 %; segments outside: 0.
- Unclipped reference SOC at the cutoff: 0.28 % to 0.62 %; maximum value 100.00 %; largest single-step increase 0.002 % (small increases come from near-zero current noise before the load switches on). No clipping is applied.
- Integration to the end of the record (including the deeper 2.5/2.2 V cutoffs of B0006/B0007/B0018 and rest samples) gives up to 1.0172 times `Capacity`, which is why segments stop at 2.7 V, the cutoff the README gives for `Capacity`.

## Reference status

The reference is **defensible but approximate**: it is coulomb counting, not a measured SOC. Its known limitations:

- The denominator is the measured capacity of the *same* discharge, which is only known after that discharge ends. The reference is therefore cycle-specific (0 % = 2.7 V cutoff at 2 A), not an absolute thermodynamic SOC.
- It applies only to this dataset's protocol: full charge, then 2 A constant-current discharge at 24 °C ambient. It says nothing about dynamic loads, partial charges or other temperatures.
- Integration error relative to `Capacity` is up to about 0.6 % of capacity (see figure `soc_reference_quality.png`).

## Held-out validation

Trained on B0005, B0006, B0007; tested once on all 132 discharge segments (31921 samples) of B0018. Model chosen by grouped CV MAE: **RandomForest**. Selected features (RFECV, training batteries only): voltage_measured_V, elapsed_s, temp_rise_C, voltage_drop_V, dvdt_past_V_per_s.

## Decision

Dashboard inclusion is controlled by `soc.dashboard_enabled` in `config.yaml` together with `reference_defensible` in the saved metadata. Inclusion is justified only within the scope above: the model reproduces an approximate coulomb-counting reference for a 2 A constant-current discharge from full charge on an unseen battery of the same test campaign. It is not validated for other load profiles, temperatures, partial-charge starts, or different cells. Errors are largest in the middle of the discharge (reference SOC bin (20, 40] %: MAE 3.20, max 7.64), so read the error table before relying on an individual estimate.
